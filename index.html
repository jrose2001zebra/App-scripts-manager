Update this manager on GitHub

  1. Save the new file. Open the updated Apps Script Manager HTML file from ChatGPT. Tap the Share button, choose Save to Files, pick a folder, and tap Save.
  2. Name it index.html. In the Files app, press and hold the saved file, then tap Rename. Use a lowercase i. If Files hides the .html extension, rename the visible part to index and keep the HTML extension.
  3. Open your GitHub repository. In Safari, open App-scripts-manager and sign in if needed. On the Code tab, stay in the main file list on the main branch.
  4. Upload the replacement. Tap Add file → Upload files → choose your files. Browse to your saved index.html and select it. Uploading the same filename here updates the existing file.
  5. Commit the update. Add a short message such as “Update manager V2.33.” Choose Commit directly to the main branch, then tap Commit changes.
  6. Open the updated manager. GitHub Pages publishes automatically using your existing settings. Allow up to 10 minutes, then refresh your usual manager link in Safari and check the version in the title. You can also find the link under Settings → Pages → Visit site.
The complete filename must be index.html — all lowercase, with no extra number or second .html.
